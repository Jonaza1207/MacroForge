## How to Add Images

1. Place the `.png` (or `.webp`) file in `src/assets/products/`
2. Add a new entry to `DOTERRA_NAME_MAP` in `src/data/images.js`:

```javascript
'Product Name Exactly As In Catalog': 'Filename-Without-Extension',
```

Example:
```javascript
'Lavanda': 'doTERRA-Lavanda',
```

3. Run `npm run build` to verify.

No component changes required — the resolver already calls `resolveDoTERRAImage(p.n)` as a fallback.
