## Format: one page per topic

Each page needs:
- H1: clear answer to the search query
- 200–400 words of honest, educational content (no fluff)
- Category description (what this is, not just what we sell)
- 2–3 product recommendations with direct modal links
- One WhatsApp CTA (consultative, not salesy)
- No fake urgency. No discount claims. No reviews.

## Technical implementation

No CMS needed. Create as:
1. Static JSON entries in `src/data/guides.js`
2. A `GuidePage` component (simple text + product cards)
3. Hash-based routing: `#guia/creatina-costa-rica`
4. Each guide links to the relevant category and WhatsApp flow
